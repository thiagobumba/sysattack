# SysAttack

Sistema de gestão de projetos da Momesso Indústria de Máquinas: projetos, tarefas e marcos, Gantt, Burndown, PERT / caminho crítico, matriz de Eisenhower, Ishikawa, financeiro, documentos, changes, relatórios e Projetos Spot. Java (Servlets) + H2 embutido + HTML/CSS/JS puro, publicado como `.war` no Tomcat.
